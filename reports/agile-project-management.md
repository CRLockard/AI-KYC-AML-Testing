# Conflict Resolution

During project execution, a potential conflict occurred when the original assignment referenced Python and Pytest despite the project environment using JavaScript and Vite.

Resolution:

The testing approach was reviewed and adjusted to use Vitest because it aligned with the existing JavaScript technology stack.

This allowed the project to maintain compatibility while meeting the assignment objective of automated testing.

---

# Sprint Plan Review and Adjustment

After reviewing project requirements, sprint plans were adjusted.

Initial plan:

- Implement all testing using Python/Pytest

Adjustment:

- Migrated testing implementation to JavaScript/Vitest

Reason:

- Better alignment with the development environment
- Improved maintainability
- Consistency with previous coursework

The updated sprint plan successfully delivered automated testing and documentation within project constraints.
